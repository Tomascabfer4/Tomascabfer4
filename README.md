# 💫 Acerca de mí

<picture>
  <img align="right" src="https://github.com/7oSkaaa/7oSkaaa/blob/main/Images/Right_Side.gif?raw=true" width="250px">
</picture>

Con una sólida base técnica que incluye un **Título Superior en Aplicaciones Multiplataforma (DAM)**, un **Título Medio en Sistemas Microinformáticos y Redes (SMR)**, y actualmente cursando el **Título Superior en Desarrollo de Aplicaciones Web (DAW)**, me defino como un desarrollador Fullstack en constante evolución.

Mi stack principal se centra en el ecosistema JavaScript moderno, especializándome en **React** y **Next.js** para frontend, respaldado por experiencia previa en **Java** y **.NET** para backend. Trabajo de forma habitual con **Inteligencia Artificial**, integrando modelos y APIs para potenciar aplicaciones y automatizar flujos. También tengo experiencia en **Docker, AWS, Firebase, Cloudflare y Supabase** para despliegues escalables.

💭 **Puedes preguntarme sobre:**  
React, Next.js, Vue, JavaScript, TypeScript, Node.js, Java, C#, .NET, HTML, CSS, SCSS, Tailwind, API REST, MongoDB, SQL, PostgreSQL, Supabase, Firebase, Cloudflare, Netlify, Vercel, Python e integración de IA (LLMs).

⚡ **Curiosidades sobre mí:**
- Tengo afición por los videojuegos desde pequeño.
- Antes de dedicarme por completo al desarrollo, empecé un proyecto de **DJ**, que mantengo como hobby.
- Me apasiona el hardware: mantenimiento y reparación de ordenadores, móviles y consolas, además de modding/jailbreak en distintos sistemas.

## 📃 Desarrollo personal

Actualmente estoy centrado en mis estudios de **DAW**, perfeccionando arquitecturas avanzadas en **Next.js** y explorando nuevas formas de implementar agentes de IA en entornos web. También continúo formándome en ciberseguridad y hacking ético para reforzar la seguridad de mis desarrollos.
